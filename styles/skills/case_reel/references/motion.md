# Motion: transitions and frame counts (30 fps)

## Captions

Body chunk: 2-frame fade-in, hard cut out. Headline lines: 2-frame fade-in per line. Hook key phrase: letters roll up 8–12 f. Details in `captions.md`.

## Transitions

| Transition | Use | Frames |
|---|---|---|
| Hard cut | presenter re-frames, into/out of B-roll, between montage images | 0 |
| Location change (hook → main) | end of the hook | hard cut on a phrase boundary |
| Soft warm flare | into client B-roll | 6–10 f |
| Strobe | montage | 2 f per image |
| Film-burn leak + tinted re-entry | section turn into the lesson (or any big turn) | 8–12 f burn + 4–6 f tint settle |
| Colour leak | section turn into the CTA | 8–12 f |
| Phone/UI overlay | context moment | 3–4 f fade in/out |

No whip pans, spins, glitches, zoom punches or white flashes — the energy comes from counters, the montage and the leaks.

## Element motion

| Element | Entry | Hold | Exit |
|---|---|---|---|
| Slot-roll digits | scroll 15–20 f, columns staggered 2–3 f | static | with the section |
| Metric word | typed, 2 f per character | static | with the counter |
| Falling icons | gravity drop + one bounce, 1–1.5 s | pile static | with the counter |
| Progress bar | grows 15–20 f, ease-out | static | with the counter |
| Partner badge | scale 0.6 → 1.05 → 1.0, 6 f | static | hard cut with the chunk |
| Agency mark | offset 0.05 W + 0.9 → centre + 1.0, 6–8 f | static | with the chunk |
| B-roll still | — | push 1.00 → 1.05 | hard cut |

## Pace check

Count changes per 10 s (cut, B-roll, device, leak). Target 3–5 in the strategy/test sections, 2–3 in the result and lesson.

# Look: grade per section, palette, fonts

## Grade

- **Main location (challenge → CTA):** warm, low-key, cinematic — lamp-lit practicals, rich shadows, skin warm, saturated wardrobe kept; gentle contrast, no crushed blacks.
- **Hook:** may be a different location; if it is, keep it brighter and airier than the main location so the hook reads as a separate "cover".
- **Client media:** keep its own commercial grade; don't push it toward the main location.
- Two cameras in one location: match exposure and white balance.

## Palette

| Role | Default | Brand override |
|---|---|---|
| Caption type | white `#FFFFFF` | white (or near-black on light media) |
| Accent (progress bar, small rules) | fresh green `#3BE38C` | the agency's accent |
| Counter capsule line | white 60–70 % | white |
| Leak (warm burn) | `#FF3B2F` → `#FF9A3C` → `#FF7AC8` | keep warm; may lean toward the accent |
| Soft colour leak | magenta `#FF4FA3` | the accent |
| Partner badges | the partner's own colours (with permission) | — |

## Fonts (free defaults; use the brand's fonts when given)

| Role | First choice | Alternatives | Notes |
|---|---|---|---|
| Body captions, headlines | **Inter** Regular/Medium (numbers Bold) | Helvetica-like grotesks: Manrope, DM Sans | small sizes; check glyphs for the clip's language |
| Hook lead words | Inter Light | Manrope Light | large and light |
| Hook key phrase | **Bebas Neue** or Oswald (caps) with outline + shine | Anton | one phrase only |
| Counters | **Inter** Bold / SemiBold, tabular figures | Manrope Bold | digits must not jump in width while rolling |

All SIL OFL. Install them and verify the tool reports the exact face. If the brand has fonts, use those and keep the hierarchy.

# Beat map: moment → device

Anchor every device to the word that triggers it (audio onset). Most beats are presenter + body caption; devices mark the moments below.

## Device table

| The speech has | Device | Anchor | Length |
|---|---|---|---|
| The promise number in the hook | **Slot-roll counter in a capsule**, metric word under it, metric icons falling and piling (only when the metric has an obvious icon: money, views, likes, orders) | the number word | until the next number or the end of the hook |
| A second hook number | **Counter + progress bar** (big number, bar filling under it, small label) | the number word | until the hook ends |
| The client's name / what they had | **Client B-roll** with the client's mark (from their media), soft flare in | the name | 2–4 s, 1–3 shots |
| Each strategy item that is a thing you can show | **B-roll of that item** (the ad, the page, the product) | the item word | 1.5–3 s |
| A named partner, platform, channel or payment method | **Partner badge** pop (their colours, stacked if several) | the name | the chunk |
| "Tested / different / variations / creatives / versions" | **Strobe montage** of the real work, 2 frames per image | the plural/variation word | 0.8–1.4 s |
| A vertical-video or app context ("on Reels", "in the feed") | **Phone/UI frame overlay** around the presenter | the context word | 0.8–1.5 s |
| Each result number | **Bold number in the caption**, plus a slot-roll counter for the 1–2 biggest numbers | the number word | the chunk |
| The lesson's contrast ("not about X, it's about Y") | **Client B-roll** under the first half, presenter on the second | "not" / "because" | 2–4 s |
| A section turn (into lesson, into CTA) | **Film-burn light leak** (+ tinted re-entry) or a soft colour leak | the first word | 8–12 f |
| The agency named in the CTA | **Agency mark** pops under the caption | the name | ~0.8–1.2 s |
| Plain talk | presenter + body caption; re-frame on phrase boundaries | — | 3–8 s per shot |

## Density rules (any length)

| Element | Rate |
|---|---|
| A change (cut, B-roll, device, leak) | at least every 4 s; presenter stretches ≤ 8 s |
| Counters (slot-roll) | ≤ 3 in the whole film; the hook always has one when a fact backs it |
| Partner badges | one per named partner, no more than 3 on screen at once |
| Strobe montage | 1 per film, 2 in films > 90 s |
| Light leaks | at section turns only, ≤ 1 per 15 s |
| Client B-roll share | 15–30 % of the runtime |
| Headline captions | ≤ 1 per section, 2–3 per film |

- Never invent a device for a number the user can't back up — keep it as plain caption text.
- Don't put a badge, a counter and a B-roll on the same 2 seconds; one device per moment.

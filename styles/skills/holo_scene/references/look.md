# Look: palette, fonts, grade

## Palette

| Role | Default | Notes |
|---|---|---|
| Hologram | cyan `#5FF2E6` | edge lines, fill, glow; the only hologram colour |
| Heat / metal | hot orange `#FF7828`, core `#F2D08C` | only when the claim is heat, melting or metal |
| Type | white `#FFFFFF` + soft black shadow (35 %, blur 0.1 × size, offset 0.04 × size) | key words, lines |
| Small function words | white at 75–78 % | inside lines |
| Brand dark | the brand's darkest colour (default navy `#122A39`) | end card background; type over bright frames |
| Accent | the brand accent (default `#E88C5C`) | URL on the end card, one accent at most |

No gradients on type, no outlines, no boxes behind captions.

## Fonts (free / OFL defaults; swap for brand fonts)

| Role | Default | Alternatives |
|---|---|---|
| Key words | Inter (opsz 32, weight 800 ExtraBold) | Manrope ExtraBold, Montserrat ExtraBold, Gilroy-like grotesks |
| Lines, lead line, labels | Inter (opsz 20, weight 600–650; function words 500) | Manrope SemiBold |
| Lower captions on product beats | sans semibold + an italic serif (e.g. Playfair Display Italic) | Cormorant Italic |

Check that every font has the language's letters (e.g. oʻ, gʻ, ş, ı, Cyrillic) before planning.

## Grade

- Match, don't stylise. Interiors and shaded sets slightly warmer (+150–200 K equivalent), contrast +3–5 %.
- Calm saturated brand-irrelevant colours that compete with the cyan (e.g. a red machine or sign −10–15 % saturation).
- A light uniform grain over everything, footage and CGI, so they sit together (σ ≈ 1.5/255 at half resolution).

## Brand override

The brand mark and the dark colour go on the end card. The accent is used for the URL only. The hologram stays cyan unless the brand's own colour is a light, saturated cool colour, in which case that colour replaces cyan everywhere.

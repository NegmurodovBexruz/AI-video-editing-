# Look: palette, fonts, grade

## Grade

- Keep the interview's own look (often warm, low-key, practical lamps). Gentle contrast; no colour cast toward the spotlight colour; no vignette added.
- Work B-roll and place photos keep their own look; match exposure so the cuts don't jump.

## Palette

| Role | Default | Brand override |
|---|---|---|
| Spotlight words, echo, pattern blocks | flat yellow `#FFE600` | the brand's brightest accent (must stay legible on dark footage) |
| Body words, script accents | white `#FFFFFF` | white |
| Split-layout panel | near-black `#161616` | the brand's darkest colour |
| Metaphor / landmark illustrations | white–grey monochrome | same |
| Place type (two-tone) | colours sampled from the photo (a cool + a warm) | the brand's two main colours |

One spotlight colour per film.

## Fonts (free defaults; use the brand's fonts when given)

| Role | First choice | Alternatives | Notes |
|---|---|---|---|
| Spotlight words, place type | **Inter** ExtraBold/Black | Montserrat ExtraBold, Archivo Black | heavy, not condensed |
| Body words | Inter Medium | DM Sans Medium | small |
| Script accents | **Great Vibes** / **Allura** | Sacramento, Pinyon Script | must be writable as a stroke animation; check glyphs for the language |

All SIL OFL. Install and verify the exact face (no silent fallback); check that the script font covers the clip's language — if not, drop script accents rather than mix fonts.

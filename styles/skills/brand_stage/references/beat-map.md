# Beat map: speech → device

Work from word onsets. A **beat** is one idea (2–6 s). Most beats stay on the speaker with captions only; the stage is reserved for the moments below. Anchor each device to the word that triggers it.

## Device table

| The speech does | Device | Anchor | Length |
|---|---|---|---|
| Opens the film | **Brand-mark sting** over the speaker | frame 0 | ≤ 0.7 s; captions start when it clears |
| Names several items in a row (tools, products, services, channels, steps) | **Branching diagram on the stage**: iris-to-dot from the speaker, a line grows from the dot and branches; the camera travels along it, one **item card** per name, label typed on | the first name; each card arrives on its own name | 0.7–1.0 s per item, 3–6 s total |
| Names one item that has a strong identity of its own | **Item colour card**: the item's card on a field of the item's own colour | the name | 0.4–1.0 s, at most once per diagram |
| Mentions items in passing while talking | **Edge tiles**: white rounded tiles with the items' marks/labels slide in at the frame edges around the speaker | each name | for the chunk |
| States the big idea / a phrase the speaker leans on ("the real shift", "a new way to work") | **Concept badge on the stage**: glitch-smear in, logotype (small caps + large script) drops in, glowing rings expand | the phrase's first content word | 2–3 s; a second badge may follow for a paired phrase |
| Lists actions or attributes | **UI-tag caption** on the speaker | the first item | the list |
| Talks about own work, clients, results ("at our studio", "for brands like…") | **Portfolio cards on the stage**: phone-shaped cards scale in one after another, brand tag inside, slow push | the brand/studio name or "we" + verb | 1.5–3 s per card, 2–4 cards |
| Describes imagination, vision, scale, "what's possible" | **Full-screen showcase B-roll** with captions on top | the image word | 2–4 s per shot, ≤ 3 shots |
| Describes change, speed, disruption ("falls apart", "changes everything", "gone in a week") | **Particle disintegration** of the current B-roll/still | the change verb | 1.5–2.5 s |
| Section turn | hard cut + re-frame, or a stage entry if one is due | first word | — |
| Closes / call to action | **Brand-mark sting** resolving to the static mark over live footage | the last phrase | last 1.5–2 s |
| Plain talk | **Speaker + captions**; re-frame cuts on phrase boundaries | — | 3–8 s per shot |

## Density rules (any length)

| Element | Rate |
|---|---|
| Speaker share of runtime | 50–60 % |
| A stage or B-roll moment | every 10–15 s of speech |
| One stage section | 3–8 s; then back to the speaker for ≥ 3 s |
| Concept badge | ≤ 1 per 25 s (a paired second badge counts as one) |
| Branching diagram | when ≥ 3 items are named together; ≤ 1 per 45 s |
| Portfolio sequence | ≤ 1 per 45 s |
| Particle disintegration | ≤ 1 per 45 s |
| UI-tag caption | ≤ 1 per 30 s |
| Speaker shots | 3–8 s; cut or re-frame on phrase boundaries |

- Never two stage sections back to back without the speaker between, except diagram → item colour card.
- Short clips (< 30 s): sting + one stage moment + one B-roll or badge is enough. Long clips: keep the rates and vary the device types; don't repeat the same device twice in a row.

# Look: grade, stage colour, fonts

## Footage grade

- Clean, slightly cool and slightly desaturated (saturation −10…−15 %), soft contrast, high-key background; skin natural. No vignette, no dark bands, no grain, no colour cast toward the stage colour.
- Two cameras: match exposure and white balance so the re-frames read as one shot.

## Stage colour

- **Brand override (normal case):** the brand's primary colour is the stage centre; the edge stop is the same hue ≈ 40 % darker. If the brand colour is light (yellow, pastel), keep it as the stage and switch stage type and lines from white to the brand's dark colour.
- **Default (no brand kit):** deep royal blue — centre `#0A1494`, edge `#03064F`.
- Item colour cards use the item's own identity colour for one beat only.

## Palette

| Role | Value |
|---|---|
| Stage | brand colour radial (centre → ≈ 40 % darker edge) |
| Type, lines, rings, labels | white `#FFFFFF` (or the brand's dark colour on a light stage) |
| Caption glow | white at 20–30 % |
| Tiles | white `#FFFFFF`, shadow black 20 % |

## Fonts (free defaults; use the brand's fonts when given)

| Role | First choice | Alternatives | Notes |
|---|---|---|---|
| Captions | **Inter Display** SemiBold/Bold (content), Medium (function words), tracking −3…−5 % | Inter (tight tracking), Manrope | neutral grotesk, mixed case; check glyphs for the clip's language |
| Labels, tiles, UI tags | Inter Medium | DM Sans | small sizes |
| Badge small word | Inter Display Bold caps, +10 % tracking | Montserrat Bold | |
| Badge script word | **Allura** / **Great Vibes** | Pinyon Script | flowing, legible at a glance |

All SIL OFL. Install them and verify the tool reports the exact face (no silent fallback). If the brand has its own fonts, use those and keep the size hierarchy.
